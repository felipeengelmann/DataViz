Status picks a ladder, not a slice. Two states are Healthy / Poor, three add Fair, four are the severity scale critical → low, five to eight add Healthy, Not applicable, No data (hatched) and Informational. Nine or more states cannot be encoded by color.
Ramps are sampled evenly. Five sequential steps use the designed 5-step ramp; other counts sample the 7-step ramp so ends stay dark and light. Even diverging counts drop the neutral midpoint — use odd counts when “on target” is a real state.
Value-mapped charts reverse status. On the heatmap a higher value is worse, so classes run Healthy → Critical; on the gauge a higher score is better, so bands run Critical → Healthy. Developers bind by key; the order is a chart decision.
