4 · Metric registry

This is where consistency comes from. Each metric is defined once, with its chart type, palette and the exact token for each value. Every dashboard showing that metric reads from this entry, so Windows is the same blue everywhere and Critical is always the same red.

Rules
1. No chart ships without a registry entry for its metric.
2. A color key is permanent. A category keeps its color even when it is filtered out, so the others do not shift.
3. The sort order is part of the entry. States sort by severity, never by value.
4. Diverging entries must name the midpoint.
